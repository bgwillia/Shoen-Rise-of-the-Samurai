# Placeholder provenance

The foundation uses Unreal Engine's built-in BasicShapes Cube and BasicShapeMaterial, plus original arrangements created by project C++ code. No marketplace or third-party game art is imported. The generated Foundation map is an actual Unreal package created by `tools/create_foundation.py`.

These are technical placeholders, with no claim of Japanese architectural or military accuracy. No final meshes, textures, animation, audio, or approved concept art are included. The user's asset-production workbook remains the later visual-production backlog; no approval/QA status in that workbook has been changed.

Engine content remains subject to the Unreal Engine license; this repository references the installed engine rather than copying its source assets into the project.

Milestone 2 adds original runtime-generated gable-roof and triangulated terrain meshes, plus instanced engine cubes for storehouse walls, preview outlines and the build boundary. Their shapes/colors are temporary. Building and terrain tuning live in project-authored JSON. No external art or engine source was copied.
