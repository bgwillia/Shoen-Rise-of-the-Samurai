# SmallShrine_01

Editable exterior: `SmallShrine01.blend`, with 26 separate construction/prop components. The revised roof follows the primary reference: side gables, an extended front eave, layered thatch and a stacked timber ridge.

Torii, offering box, lantern, fence pieces and banners have separate runtime exports. Timber, thatch, stone, rope and iron reuse the existing SHŌEN rural materials; only off-white paper/cloth was added. No interior or gameplay systems.

Remaining visual limitations: roof courses and masonry retain some regularity at close range; the test settlement has plain terrain rather than the reference's trees and planted surroundings.

Unreal: `/Game/Art/Buildings/Religion/SmallShrine01/Review/SmallShrine01_Settlement`. Open `Launch_SmallShrine01.command` for the settlement. Actual Metal editor views are in `artifacts/smallshrine01/unreal-three-quarter.png` and `unreal-settlement.png`; the source render is `shrine-three-quarter.png` in the same folder. Review lighting is temporary and is not saved into the settlement map.
