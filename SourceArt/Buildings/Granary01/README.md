# Granary_01

Editable exterior: `Granary01.blend` (13 components). Runtime export: `Exports/Granary_01.fbx`.
Reuses RuralHouse/Storehouse thatch, timber, plaster, fieldstone, rope, ridge and construction pieces. No interior; closed door. Ground-centred metre-scale source; approximately 3.8 m roof width and 4.25 m height. Unreal uses one simple collision box and the existing granary placement/preview.

Open `Launch_Granary01.command` to view it beside RuralHouse_01 and Storehouse_01. The standalone source view and actual Metal game captures are in `artifacts/granary01/` at the repository root. The comparison capture uses daylight ambient fill; the normal-camera capture is `unreal-settlement.png`.

Remaining visual issue: vents are subtle from the steep overhead strategy camera. No further modeling pass was made.
